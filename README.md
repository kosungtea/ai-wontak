# AI 원탁

Claude·ChatGPT·Gemini·Perplexity에 같은 질문을 동시에 보내고, 고른 AI가 답을 익명으로 심사(리랭킹)한 뒤 하나로 정리(앙상블)하는 채팅 앱입니다.

- 호출: OpenRouter API 키 하나로 4개 AI를 부릅니다.
- 저장: API 키와 대화 기록은 각 기기 브라우저에만 저장됩니다. 이 저장소에는 들어가지 않습니다.
- 프로젝트: 프로젝트마다 공통 지침, AI별 지침, 정리 AI 지침, 참고 자료를 따로 둡니다.
- 표시: 마크다운 표, 코드, 수식, mermaid 다이어그램, HTML 차트, SVG 그림을 화면으로 그립니다.

## 쓰는 법
1. openrouter.ai에서 키를 만들고 크레딧을 충전합니다.
2. 이 페이지를 열고 오른쪽 위 설정에 키를 넣습니다.
3. 위쪽 칩에서 AI별 모델을 고른 뒤 질문합니다.
